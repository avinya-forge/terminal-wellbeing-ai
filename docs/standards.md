# Development Standards

## Code Style
- **Language:** TypeScript (Strict mode).
- **Framework:** React (Functional components, Hooks).
- **Styling:** Tailwind CSS.
- **Formatting:** Prettier (default settings).
- **Linting:** ESLint (recommended rules).

## Testing
- **Framework:** Jest (ts-jest) or Bun test.
- **Coverage:** Aim for >80% coverage on utility logic.
- **Types:** comprehensive unit tests for core logic.

## Version Control
- **Branching:** Feature branches from `main`.
- **Commits:** Conventional Commits (feat, fix, docs, style, refactor, test, chore).
- **PRs:** squash and merge into `main`.
