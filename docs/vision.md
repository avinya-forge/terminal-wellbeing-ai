# Vision

## Purpose
A terminal-based mental health assistant designed to provide accessible, low-friction support.

## Core Values
1. **Accessibility**: Text-based interface works on any device.
2. **Privacy**: Minimal data collection, local processing where possible.
3. **Empathy**: Supportive and non-judgmental interactions.
4. **Simplicity**: Focus on the conversation, not complex UI.

## Target Audience
Individuals seeking mental health support in a familiar, text-based environment.
